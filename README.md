# 🎞️ gif-maker

**Превращает видеоклип или папку фото в лёгкий и чёткий GIF.**

[Agent Skill](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) (`SKILL.md`) плюс рабочий скрипт на `ffmpeg`. Работает с любым клиентом, который читает формат Agent Skills — Claude Code и другие. Что нужно на выходе — описываешь словами («убери интерфейс, ускорь, сделай полегче»), агент сам переводит это во флаги и запускает.

---

## Зачем

`ffmpeg -i in.mov out.gif` работает, но дефолтный энкодер ffmpeg использует фиксированную обобщённую палитру — бандинг на градиентах, а размер файла обычно раздут в 5-10 раз против возможного при том же качестве.

Скилл всегда прогоняет вместо этого стандартную двухпроходную схему:

1. `palettegen` — строит оптимальную палитру (≤256 цветов) по реальным кадрам.
2. `paletteuse` — кодирует по этой палитре, с дизерингом против бандинга.

## Что умеет

- **Видео → GIF**: обрезка по времени (`start`/`duration`), кроп (вручную или автодетект), ускорение/замедление, fps, ширина.
- **Фото → GIF**: папка или glob фото _любого_ набора разрешений/ориентаций — каждое ложится леттербоксом на общий холст, а не предполагается одинаковый размер.
- **Запросы словами**: «убери интерфейс», «ускорь», «сделай полегче» — агент читает таблицу-словарь в `SKILL.md` и сам подбирает флаги; спрашивает только когда направление запроса реально неоднозначно.
- **Настройка ffmpeg**: проверяет, есть ли `ffmpeg`/`ffprobe` в `PATH`. Нет на macOS с Homebrew — ставит сам. Нет где-то ещё — печатает точную команду под твою ОС вместо того, чтобы молча упасть.
- **Качество из коробки, без файла-эталона**: дефолты (`10fps`, `640px`, `256` цветов, `sierra2_4a`) дают качество, сравнимое с хорошим ручным энкодом, сразу после установки — ничего дополнительно подкладывать не нужно.
- **Бюджет по весу из коробки**: даже без `--max-size` вес зажат встроенным потолком (~7.8 МБ, константа в скрипте, не файл на диске).
- **Свой бюджет по весу**: `--max-size 8M` (или `--max-size other.gif` — взять вес другого файла) — если прогон больше, скрипт сам перекодирует на меньшем fps/ширине/палитре, пока не впишется, либо сообщает, что упёрся в потолок качества. Жёсткий потолок по весу может _испортить_ качество на «дорогом» контенте (видео/фото с реальным движением, шумом) — это осознанный компромисс, не побочный эффект.
- **«Не хуже конкретного файла»**: `--reference other.gif` разом фиксирует разрешение не ниже, чем у файла, _и_ вес не больше — в одном флаге; при конфликте побеждает разрешение. Работает только когда `other.gif` физически лежит на диске и явно указан флагом — скрипт никогда не ищет и не подставляет файл сам.

## Быстрый старт

### С агентом

Вставь это в Claude Code или любой клиент, читающий Agent Skills:

```text
Установи скилл gif-maker из https://github.com/it-publisher/gif-maker в этот
проект (.claude/skills/gif-maker/), затем сделай мне GIF:

Вход: [путь к видео или папка с фото]
Что нужно: [опиши словами — кроп, скорость, длина, насколько лёгкий/чёткий]
```

Агент проверит ffmpeg, посмотрит на материал, сам подберёт флаги под описание и
скажет, какой кроп/скорость/fps/размер в итоге использовал.

<details>
<summary><b>Ручная установка</b> — то же самое по шагам</summary>

```bash
# 1. Склонируй репозиторий со скиллом
git clone https://github.com/it-publisher/gif-maker.git
cd gif-maker

# 2. Скопируй скилл в папку скиллов своего клиента...
cp -r .claude/skills/gif-maker ~/.claude/skills/
# ...или используй прямо из клона проекта, без копирования никуда

# 3. Запускай напрямую, без агента — путь ниже подходит для варианта "из клона";
#    если скопировал в ~/.claude/skills/, замени его на ~/.claude/skills/gif-maker/scripts/make-gif.sh

# Видео: обрезка, кроп, ускорение, кодирование
.claude/skills/gif-maker/scripts/make-gif.sh \
  -i input.mov -o out/demo.gif \
  -s 25 -t 10 --crop auto --speed 1.5 -r 10 -w 640

# Фото: слайд-шоу, 1.5с на фото, любой набор размеров
.claude/skills/gif-maker/scripts/make-gif.sh \
  -i photos/ -o out/slideshow.gif -p 1.5 -w 720
```

Полный список флагов — `make-gif.sh -h`.

</details>

## Опции

| Флаг                             | Применимо к | Дефолт            | Что делает                                                                                                                                              |
| --------------------------------- | ----------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-i, --input`                    | оба         | —                 | видеофайл, папка фото или glob в кавычках                                                                                                              |
| `-o, --output`                   | оба         | `out/<name>.gif` | папка создаётся, если её нет                                                                                                                            |
| `-s, --start` / `-t, --duration` | видео       | весь клип         | окно обрезки                                                                                                                                            |
| `--speed`                        | видео       | `1`               | `2` = вдвое быстрее, `0.5` = вдвое медленнее                                                                                                            |
| `--crop`                         | видео/фото  | нет               | `"w:h:x:y"`, либо `auto` для детекта однотонной рамки                                                                                                   |
| `-p, --photo-time`               | фото        | `1/fps`           | сколько секунд показывать каждое фото                                                                                                                   |
| `-r, --fps`                      | оба         | `10`              | частота кадров на выходе                                                                                                                                |
| `-w, --width`                    | оба         | `640`             | ширина в px, или путь к файлу — взять ширину из него; высота авто, чётная                                                                               |
| `--colors`                       | оба         | `256`             | размер палитры, 2-256                                                                                                                                   |
| `--dither`                       | оба         | `sierra2_4a`      | `none` для плоского UI/скриншотов                                                                                                                       |
| `--stats-mode`                   | оба         | `full`            | `diff` для скринкастов — почти статичный кадр с одной движущейся областью                                                                               |
| `-m, --max-size`                 | оба         | встроенный потолок ~7.8 МБ | бюджет по весу: `8M`, `500K`, или путь к файлу — взять его размер. Больше бюджета → автоперекодирование (fps → ширина → цвета вниз), пока не впишется |
| `-R, --reference`                | оба         | нет               | «не хуже FILE» одним флагом: `-w FILE` + `--max-size FILE` вместе. `FILE` — реальный путь, который нужно указать явно, автоподстановки нет            |

Полная документация по опциям, компромиссы по размеру и таблица «слова → флаги» —
в [`SKILL.md`](.claude/skills/gif-maker/SKILL.md).

## Требования

`ffmpeg` и `ffprobe`. Скилл разбирается с этим сам — см. «Что умеет» выше — но если
запускаешь скрипт напрямую без агента:

- **macOS**: `brew install ffmpeg`
- **Debian/Ubuntu**: `sudo apt-get install -y ffmpeg`
- **Fedora**: `sudo dnf install -y ffmpeg`
- **Arch**: `sudo pacman -S ffmpeg`
- **Остальные**: https://ffmpeg.org/download.html

## Известные ограничения

- Звук всегда отбрасывается (в GIF его не бывает).
- HEIC-фото требуют поддержки `libheif` в сборке ffmpeg; если декодирование падает —
  сконвертируй сначала: macOS `sips -s format jpeg in.heic --out in.jpg`.
- `--crop auto` ловит только однотонные рамки (леттербоксинг), не произвольный UI
  рядом с контентом — там нужен ручной прямоугольник.
