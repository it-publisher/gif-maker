# 🎞️ gif-maker

**Превращает видеоклип, папку фото или готовый GIF в лёгкий и чёткий GIF.**

[Agent Skill](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) (`SKILL.md`) плюс скрипт на `ffmpeg`. Работает с любым клиентом, который читает формат Agent Skills — Claude Code и другие. Что нужно на выходе, описываешь словами («убери интерфейс, ускорь, сделай полегче») — агент переводит это во флаги сам и спрашивает, только когда направление запроса реально неоднозначно.

---

## Зачем

Дефолтный энкодер (`ffmpeg -i in.mov out.gif`) берёт фиксированную обобщённую палитру: бандинг на градиентах, а файл раздут в 5-10 раз против возможного при том же качестве. Скилл вместо этого всегда гоняет двухпроходную схему — `palettegen` строит палитру (≤256 цветов) по реальным кадрам, `paletteuse` кодирует по ней с дизерингом.

## Что умеет

- **Видео → GIF**: обрезка по времени, кроп (вручную или автодетект), ускорение/замедление, fps, ширина.
- **Фото → GIF**: папка или glob фото _любого_ набора разрешений и ориентаций — каждое ложится леттербоксом на общий холст, одинаковый размер не предполагается.
- **GIF → GIF**: готовый GIF сжимается без потери пикселей (`gifsicle -O3`, если установлен) с сохранением исходных fps и ширины; `--lossy N` — если нужно сильнее.
- **Качество из коробки**: дефолты (`10fps`, `640px`, `256` цветов, `sierra2_4a`) — константы в скрипте, ничего подкладывать рядом не нужно; у готового GIF fps и ширина берутся из источника.
- **Бюджет по весу**: встроенный потолок ~7.8 МБ действует и без флагов, свой задаётся `--max-size 8M` или `--max-size other.gif`, а `--max-size none` снимает его совсем. Не влезло — скрипт сам перекодирует на меньшем fps/ширине/палитре, пока не впишется, либо сообщает, что упёрся в потолок качества. На «дорогом» контенте (реальное движение, шум) жёсткий лимит по весу может _испортить_ качество — это осознанный компромисс, не побочный эффект.
- **«Не хуже конкретного файла»**: `--reference other.gif` одним флагом держит разрешение не ниже, а вес не выше, чем у файла; при конфликте побеждает разрешение. Файл указывается явно — сам скрипт ничего не ищет и не подставляет.
- **Настройка ffmpeg**: проверяет `ffmpeg`/`ffprobe` в `PATH`; на macOS с Homebrew ставит сам, иначе печатает точную команду под твою ОС вместо того, чтобы молча упасть.

## Быстрый старт

### С агентом

Вставь это в Claude Code или любой клиент, читающий Agent Skills:

```text
Установи скилл gif-maker из https://github.com/it-publisher/gif-maker в этот
проект (.claude/skills/gif-maker/), затем сделай мне GIF:

Вход: [путь к видео или папка с фото]
Что нужно: [опиши словами — кроп, скорость, длина, насколько лёгкий/чёткий]
```

Агент проверит ffmpeg, посмотрит на материал, подберёт флаги под описание и скажет,
какой кроп/скорость/fps/размер в итоге использовал.

<details>
<summary><b>Ручная установка</b> — то же самое по шагам</summary>

```bash
# 1. Склонируй репозиторий со скиллом
git clone https://github.com/it-publisher/gif-maker.git
cd gif-maker

# 2. Скопируй скилл в папку скиллов своего клиента — или работай прямо из клона
cp -r .claude/skills/gif-maker ~/.claude/skills/

# 3. Запускай без агента. Пути ниже — для варианта «из клона»;
#    после копирования это ~/.claude/skills/gif-maker/scripts/make-gif.sh

# Видео: обрезка, кроп, ускорение, кодирование
.claude/skills/gif-maker/scripts/make-gif.sh \
  -i input.mov -o out/demo.gif \
  -s 25 -t 10 --crop auto --speed 1.5 -r 10 -w 640

# Фото: слайд-шоу, 1.5с на фото, любой набор размеров
.claude/skills/gif-maker/scripts/make-gif.sh \
  -i photos/ -o out/slideshow.gif -p 1.5 -w 720

# Готовый GIF: сжать lossless, сохранив fps и ширину
.claude/skills/gif-maker/scripts/make-gif.sh \
  -i existing.gif -o out/smaller.gif
```

Полный список флагов — `make-gif.sh -h`.

</details>

## Опции

| Флаг | Применимо к | Дефолт | Что делает |
|---|---|---|---|
| `-i, --input` | оба | — | видеофайл, папка фото, glob в кавычках или готовый `.gif` |
| `-o, --output` | оба | `out/<name>.gif`, если папка `out/` есть, иначе `./<name>.gif` | папка создаётся, если её нет |
| `-s, --start` / `-t, --duration` | видео/GIF | весь клип | окно обрезки. `-t` применяется до `--speed`, итог = `t/speed` |
| `--speed` | видео/GIF | `1` | `2` = вдвое быстрее, `0.5` = вдвое медленнее |
| `--crop` | оба | нет | `"w:h:x:y"`; `auto` (видео/GIF) — детект однотонной рамки |
| `-p, --photo-time` | фото | `1/fps` | сколько секунд показывать каждое фото |
| `-r, --fps` | оба | `10` | частота кадров. Для фото задаёт только дефолт `-p` — реальный fps = `1/photo-time`; для GIF по умолчанию берётся из источника |
| `-w, --width` | оба | `640` | ширина в px или путь к файлу — взять ширину из него; высота авто, чётная. Для GIF по умолчанию берётся из источника |
| `--colors` | оба | `256` | размер палитры, 2-256 |
| `--dither` | оба | `sierra2_4a` | `none` для плоского UI/скриншотов |
| `--stats-mode` | оба | `full` | `diff` для скринкастов — почти статичный кадр с одной движущейся областью |
| `--loop` | оба | `0` | `0` = бесконечно, `-1` = один раз, `N` = повторов |
| `-m, --max-size` | оба | встроенный потолок ~7.8 МБ | бюджет по весу: `8M`, `500K` или путь к файлу — взять его размер. Больше бюджета → автоперекодирование (fps → ширина → цвета вниз), пока не впишется. `none` снимает потолок совсем |
| `--lossy N` | все | `0` | уровень lossy-сжатия gifsicle, 0-200: больше = легче и чуть менее точно. Требует gifsicle |
| `-R, --reference` | оба | нет | «не хуже FILE» одним флагом: `-w FILE` + `--max-size FILE` вместе. `FILE` указывается явно, автоподстановки нет |

Полная документация, компромиссы по размеру и таблица «слова → флаги» —
в [`SKILL.md`](.claude/skills/gif-maker/SKILL.md).

## Требования

`ffmpeg` и `ffprobe` — скилл ставит их сам или подсказывает команду. Вручную:
`brew install ffmpeg` (macOS), `sudo apt-get install -y ffmpeg` (Debian/Ubuntu),
`sudo dnf install -y ffmpeg` (Fedora), `sudo pacman -S ffmpeg` (Arch),
[остальные ОС](https://ffmpeg.org/download.html).

`gifsicle` — необязателен: если он есть, готовый GIF оптимизируется lossless-режимом
`-O3`, а `--lossy N` становится доступен. Поставить: `brew install gifsicle` (macOS)
или `sudo apt-get install -y gifsicle` (Debian/Ubuntu).

## Проверка

```bash
bash tests/smoke.sh    # ~5 секунд, нужен только ffmpeg
```

Smoke-тесты гоняют видео, слайд-шоу с разными пропорциями, бюджет, `-R`, glob,
GIF-оптимизацию и внятность ошибок. Те же проверки плюс `shellcheck` идут в CI
на Linux и macOS.

## Известные ограничения

- Звук всегда отбрасывается (в GIF его не бывает).
- HEIC-фото требуют поддержки `libheif` в сборке ffmpeg; если декодирование падает —
  сконвертируй сначала: macOS `sips -s format jpeg in.heic --out in.jpg`.
- `--crop auto` ловит только однотонные рамки (леттербоксинг), не произвольный UI
  рядом с контентом — там нужен ручной прямоугольник.
- Без `gifsicle` готовый GIF всё равно пересобирается, но через ffmpeg — без
  lossless-оптимизации кадров и без `--lossy`.
